# 🌙 Lunara

Una plataforma moderna para crear detalles virtuales con animaciones, música y videos.

---

## ✨ Características

- ❤️ Plantillas para ocasiones especiales.
- 🎵 Música personalizada.
- 🖼️ Fotos y videos.
- 🎬 Exportación a MP4.
- 📱 Diseño responsive.
- 🌌 Animaciones premium.
- 🔗 Compartir mediante enlace.

---

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- SQLite
- Render
- GitHub

---

## 🚀 Instalación

```bash
npm install
npm start
```
